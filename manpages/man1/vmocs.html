vmocs

Synopsis

vmocs [--config PATH] [--version] <command> [<args>]

Description

vmocs is a lightweight QEMU/KVM wrapper for launching and managing virtual machines inside SLURM jobs. It reads VM templates from a YAML configuration file and handles SSH key injection, port allocation, QMP lifecycle management, and optional memory snapshots for fast restores.

Global Options

--config PATH

Path to vmocs.yaml. Defaults to confs/vmocs.yaml relative to the working directory.

--version

Print the vmocs version and exit.

Commands

launch

Launch a VM from a template. See vmocs-launch(1).

run

Launch a VM and execute a command inside it over SSH. See vmocs-run(1).

list

List running VMs. See vmocs-list(1).

stop

Stop a running VM. See vmocs-stop(1).

template

List and inspect VM templates. See vmocs-template(1).

snapshot

Create VM snapshots for fast boot. See vmocs-snapshot(1).

Files

confs/vmocs.yaml

Main configuration file. See vmocs.yaml(5).

confs/templates.yaml

VM template definitions. See vmocs-templates.yaml(5).

See Also

vmocs-launch(1), vmocs-run(1), vmocs-list(1), vmocs-stop(1), vmocs-template(1), vmocs-snapshot(1), vmocs.yaml(5), vmocs-templates.yaml(5)
